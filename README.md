# KATA releases

Installers and the update feed for KATA's private beta. KATA's source code is not here.

KATA checks this repository for new versions and asks before downloading one. It never updates
without asking.

The beta installer is not code-signed yet, so Windows SmartScreen shows a warning when you run it.
Beta testers get install steps with their invitation.

KATA is closed-source beta software. All rights reserved.
